# 박주호 포트폴리오 디자인

## Direction

업무 경험을 한 장씩 읽는 개인 기록집. 주인공은 실제 인물과 경험이며, 3D는 웹·AI 활용·CCTV의 관계를 보여 주는 보조 장치다. 기존 파란색 정체성, 공개 접근, 카드 단위 전환, 항상 켜진 모션을 유지한다. 사용자가 이미 지정한 방향과 즉시 개선 요청을 근거로 추가 승인 단계 없이 진행했다.

## First viewport

- 1920×1080 기준 외곽 카드 1744×920px, 모든 카드 내부 여백 48px.
- 왼쪽 사진·이름 위에 별도 장식 문구를 쌓지 않는다. 사진은 큰 화면에서도 160×205px 고정 크기로 유지하고, 좁거나 낮은 화면에서만 더 작게 조정한다.
- 사진과 짧은 소개는 같은 열, 3D는 오른쪽 열을 사용한다. 가운데 독립된 빈 열을 만들지 않는다.
- 웹 개발, AI 활용, CCTV·네트워크는 동일한 장면 선택 버튼을 갖는다.
- 제목은 ‘웹을 만들고, 현장까지 살핍니다.’로 시작한다.

## Visual system

자체 제공 Pretendard Variable 한글 서체. 잉크 #142841, 본문 보조색 #53657c, 코발트 #244dc5, 밝은 종이색 #edf1f6. 첫 소개만 별도 제목 크기를 쓰며 일반 섹션 제목은 28–48px의 공통 크기를 따른다. 본문 16–18px, 짧은 보조 정보 13–15px. 제목 자간은 -0.04em보다 좁히지 않는다.

배경 전체에 그라데이션이나 장식 효과를 반복하지 않는다. 모서리는 외곽 카드 24px, 실내용 패널 16px, 작은 버튼 8px를 기준으로 한다. 정보 목록은 구분선으로 읽고, 실제 프로젝트만 독립 링크 카드로 묶는다.

모든 섹션의 본문은 카드 안쪽 너비 전체를 사용한다. 섹션별 max-width를 추가하지 않는다. 좌우 여백은 --card-padding, 주된 열 간격은 --layout-gap, 제목 아래 간격은 --section-gap, 목록 상하 여백은 --row-space, 패널 내부 여백은 --panel-padding으로 관리한다. PC 기본은 48 / 32 / 32 / 24 / 32px, 작은 화면은 공통 미디어 쿼리에서 한 번에 조절한다. 두 열을 사용하는 소개·업무 태도·프로젝트·학력·연락처는 같은 열 비율을 따른다.

## Chapter grammar

소개는 사진·텍스트·입체 오브젝트. 일하는 방식은 짧은 문장과 세 가지 구체적 태도. 경력은 상단 제목 아래 날짜·회사와 직무·담당 업무를 구분한 전체 너비 목록이다. 큰 PC에서는 세 열, 작은 PC에서는 날짜와 본문 두 열, 모바일에서는 회사 선택 한 열로 구성한다. 기술은 다섯 동일 위계의 목록. 프로젝트는 현재 사이트와 이전 자료를 구분한 확장 가능한 항목. 학력·자격은 두 개의 기록 열. 연락처는 밝은 바탕에 이메일·휴대폰과 근무 지역·관심 분야를 같은 행 크기로 배치한다. 이메일을 별도 배너나 큰 원형 버튼으로 강조하지 않는다.

## Motion and interaction

카드 전환은 0.76초. 한 번의 휠 입력은 한 섹션 이동이며 제스처의 관성 꼬리를 차단한다. 키보드·터치·직접 링크도 같은 전환을 사용한다. GSAP 단일 타이머가 소개 전환 게이지를 관리한다. 장면 선택 시 텍스트, 카드와 3D 배경, 모델 초점이 함께 변한다.

소개는 순차 등장, 일하는 방식은 면 펼침과 행 진입, 경력은 가로 목록 진입, 기술은 3D와 목록의 시차 등장, 프로젝트는 얕은 원근 등장, 학력은 작은 수직 이동, 연락처는 네 정보 행의 동일한 짧은 등장으로 구분한다. 이동 완료 후 텍스트의 transform·clip을 해제한다.

## Responsive and accessibility

850px 아래에서는 모바일 메뉴와 회사 선택을 사용한다. 600px 아래 첫 소개의 3D는 생략하고 기술 섹션의 작은 3D를 유지한다. 짧은 화면에서는 사진·제목·간격을 줄인다. 일반 카드에는 별도의 ‘전체 보기’ 버튼을 두지 않으며, 교육 상세만 명시적인 대화상자를 사용한다.

모바일 경력은 한 줄의 회사 선택, 날짜·재직 상태, 회사명, 직무·직급, 업무 목록 순서로 읽는다. 중복된 섹션 설명은 접고 본문 16px을 확보한다. 같은 회사를 재선택하면 애니메이션을 다시 시작하지 않는다. 태블릿에서도 선택된 회사의 날짜와 본문은 한 열로 배치한다.

포커스 표시, 스킵 링크, 실제 링크, 비활성 섹션 inert, 대화상자 닫기·포커스 복귀를 유지한다. 주요 조작 영역 44px 이상. 현재 위치는 숫자·텍스트·메뉴 상태로 전달한다. 사용자가 모션 상시 사용과 토글 제거를 명시했으므로 이 프로젝트에서는 OS의 모션 축소 설정으로 전환을 끄지 않는다.

## Verification limits

현재 실행 환경의 관리형 미리보기 서비스가 없어 실제 브라우저 레이아웃과 GPU 이미지는 검증하지 못했다. 자동 동작 테스트, 구문·CSS 파싱, 색상 대비, 실제 3D 지오메트리 검증만 완료한 것으로 구분한다. 계산된 뷰포트 설계값은 렌더링 증거를 대체하지 않는다.
