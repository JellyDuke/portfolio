# 박주호 포트폴리오 디자인

## Direction

업무 경험을 한 장씩 읽는 개인 기록집. 2026-09-23 사용자가 제공한 시안 7장을 기준으로 1·2·7번은 파란 리본 배경을 화면 전체에 사용하고, 3~6번은 흰 기록 카드로 구성한다. 실제 인물과 경험이 중심이며, 기존 파란색 정체성, 공개 접근, 카드 단위 전환, 항상 켜진 모션을 유지한다. 실시간 3D는 기술·활용 섹션에서만 사용한다.

## First viewport

- 1920×1080 기준 외곽 카드 1744×920px, 모든 카드 내부 여백 48px.
- 왼쪽 사진·이름 위에 별도 장식 문구를 쌓지 않는다. 시안의 세부 크기를 맞추라는 후속 요청에 따라 사진은 원본 128×164px 비율로 확대·축소하되 기존 160×205px 상한을 넘지 않는다.
- 사진과 소개는 왼쪽, 제공된 리본 배경의 큰 오브젝트는 오른쪽에 놓는다. 배경 위에 별도 3D 상자를 겹치지 않는다.
- 웹 개발, AI 활용, CCTV·네트워크는 동일한 장면 선택 버튼을 갖는다.
- 제목은 ‘웹을 만들고, 현장까지 살핍니다.’로 시작한다.

## Visual system

자체 제공 Pretendard Variable 한글 서체. 잉크 #142841, 본문 보조색 #53657c, 코발트 #244dc5, 밝은 종이색 #edf1f6. 1·2·7번은 큰 제목을 사용하고 일반 기록 섹션은 28–48px의 공통 제목 크기를 따른다. 본문 16–22px, 짧은 보조 정보 13–15px. 제목 자간은 -0.04em보다 좁히지 않는다.

새 장식 이미지나 효과를 추가하지 않고 제공된 배경 3개를 사용한다. 모서리는 기록 카드 24px, 실내용 패널 16px, 작은 버튼 8px를 기준으로 한다. 배경 중심 섹션은 외곽 카드의 흰 면과 그림자를 제거한다. 정보 목록은 구분선으로 읽고, 실제 프로젝트만 독립 링크 카드로 묶는다.

모든 섹션의 본문은 카드 안쪽 너비 전체를 사용한다. 섹션별 max-width를 추가하지 않는다. 기록 카드의 여백은 --card-padding, --layout-gap, --section-gap, --row-space, --panel-padding으로 관리한다. PC 기본은 48 / 32 / 32 / 24 / 32px다. 배경 중심 섹션의 배치는 `scenic-sections.css`, 기록 카드의 시안 조정은 `editorial-sections.css`에서 관리한다. 배경 아이콘에 맞춘 비대칭 배치는 1100px보다 넓은 화면에만 적용한다.

## Chapter grammar

학력·자격 두 열의 제목과 기록은 한 그리드의 같은 행을 공유한다. 기록이 길어져도 좌우 구분선 높이가 같고, 교육 이수 블록은 그 아래에서 잘리지 않는다. 연락처의 안내 문구와 정보는 배경 리본을 가리지 않도록 좁은 오른쪽 열에 정렬한다.

두 번째 섹션의 본문·밑줄·서명은 한 묶음으로 읽히도록 간격을 좁힌다. 교육 이수 블록은 진입 중 세로로 움직이지 않아 일시적인 스크롤바를 만들지 않는다. 상세 대화상자의 닫기 버튼은 보이는 면만 낮추고 누를 수 있는 영역은 44px 이상으로 유지한다.

소개는 사진·실제 텍스트·리본 배경과 반투명 장면 선택기. 일하는 방식은 큰 제목과 배경 아이콘 아래의 세 설명이다. 3~6번에는 섹션명·번호·구분선을 공통으로 사용한다. 경력은 날짜·회사와 직무·담당 업무를 구분한 전체 너비 목록이며, 모바일에서는 회사 선택 한 열로 구성한다. 기술은 3D 보조 패널과 다섯 동일 위계의 목록. 프로젝트는 현재 사이트와 이전 자료의 두 링크 카드. 학력·자격은 두 개의 기록 열이다. 연락처는 큰 인사말을 왼쪽에, 이메일·휴대폰·지역·관심 분야를 오른쪽 한 열에 둔다. 이메일과 휴대폰의 강조 수준은 동일하다.

## Motion and interaction

짧은 화면에서 학력·자격 내용이 카드 높이를 넘을 때만 카드 내부를 스크롤한다. 휠·터치·키보드로 끝까지 읽은 다음 입력부터 다음 섹션으로 이동한다. 보통 높이에서는 기존의 한 번 입력·한 섹션 이동을 유지한다.

카드 전환은 0.76초. 한 번의 휠 입력은 한 섹션 이동이며 제스처의 관성 꼬리를 차단한다. 키보드·터치·직접 링크도 같은 전환을 사용한다. GSAP 단일 타이머가 소개 전환 게이지를 관리한다. 첫 화면의 선택기는 문구만 전환하고 제공된 배경은 유지한다. 활성 섹션의 `data-active-section`에 따라 배경 3개가 교차 전환된다. 기술 섹션은 3D 회전과 목록 반응을 유지한다.

소개는 순차 등장, 일하는 방식은 면 펼침과 행 진입, 경력은 가로 목록 진입, 기술은 3D와 목록의 시차 등장, 프로젝트는 얕은 원근 등장, 학력은 작은 수직 이동, 연락처는 네 정보 행의 동일한 짧은 등장으로 구분한다. 이동 완료 후 텍스트의 transform·clip을 해제한다.

## Responsive and accessibility

850px 아래에서는 모바일 메뉴와 회사 선택을 사용한다. 배경은 옅게 처리하고 소개·업무 태도·연락처를 읽기 순서대로 쌓는다. 600px 아래 기술 섹션은 작은 3D를 사용하되, 높이가 740px 이하이면 기술 목록을 우선해 3D를 숨긴다. 좁고 짧은 화면에서는 프로젝트의 부가 설명을 접고 제목·상태·링크를 유지한다. 일반 카드에는 별도의 ‘전체 보기’ 버튼을 두지 않으며, 교육 상세만 명시적인 대화상자를 사용한다.

모바일 경력은 한 줄의 회사 선택, 날짜·재직 상태, 회사명, 직무·직급, 업무 목록 순서로 읽는다. 중복된 섹션 설명은 접고 본문 16px을 확보한다. 같은 회사를 재선택하면 애니메이션을 다시 시작하지 않는다. 태블릿에서도 선택된 회사의 날짜와 본문은 한 열로 배치한다.

포커스 표시, 스킵 링크, 실제 링크, 비활성 섹션 inert, 대화상자 닫기·포커스 복귀를 유지한다. 주요 조작 영역 44px 이상. 현재 위치는 숫자·텍스트·메뉴 상태로 전달한다. 사용자가 모션 상시 사용과 토글 제거를 명시했으므로 이 프로젝트에서는 OS의 모션 축소 설정으로 전환을 끄지 않는다.

## 시안 좌표와 높이 보정

1·2번 원본은 1672×941px다. PC의 `--reference-unit`은 제목·버튼이 화면 안에
들어오는 배율이고, `--art-unit`은 원본 비율을 유지하며 배경을 빈틈없이 채우는
cover 배율이다. 16:9에서는 사실상 같고 다른 비율에서는 배경의 잘림 오프셋을
2번 설명 좌표에도 적용한다. 원본 PNG를 재압축하거나 가로·세로로 따로 늘리지 않는다.

## Verification limits

현재 실행 환경의 관리형 미리보기 서비스가 없어 실제 브라우저 레이아웃과 GPU 이미지는 검증하지 못했다. 자동 동작 테스트, 구문·CSS 파싱, 색상 대비, 실제 3D 지오메트리 검증만 완료한 것으로 구분한다. 계산된 뷰포트 설계값은 렌더링 증거를 대체하지 않는다.
