# v20 — consistent layout and restrained contact

## Scope

사용자 요청: PC 경력 구성 개선, 모든 섹션의 좌우 여백·간격·블록 크기 규칙 통일, 마지막 카드의 이메일 과장 제거. 추가로 공유한 Wix 세 링크는 참고 사례이며, 사용자는 그대로 따라 만들 필요가 없다고 명시했다. 파란색 정체성, 기존 3D, 한 번의 휠 입력으로 한 카드 이동, 모션 상시 사용, 공개 접근을 유지한다.

- https://ko.wix.com/website-template/view/html/wh-1438 — Family Blog: 사진과 고유 서체가 정체성을 만들고 연락처는 보조 정보로 배치.

템플릿의 사진, 문구, 브랜딩, 전체 화면 구성을 복사하지 않았다. 정렬과 정보 위계만 현재 포트폴리오에 맞게 참고했다.

## Root causes and changes

- 카드 바깥 크기는 같았지만 본문 max-width가 1350/1430/1450/1460/1500px로 달랐다. 모바일 경력만 620px 제한도 있었다. 이 제한을 없애고 모든 본문을 카드 안쪽 100% 너비와 0 좌우 margin으로 통일했다.
- 섹션마다 달랐던 큰 열 간격과 카드 안쪽 여백을 공통 변수로 정리했다. 프로젝트 두 항목은 같은 열 너비와 패딩, 모서리를 사용한다. 제목 아래 간격과 목록 행 패딩도 공유한다.
- PC 경력 제목이 왼쪽에 큰 별도 열을 차지해 본문을 좁혔다. 제목 아래 전체 너비 목록으로 바꾸고, 1201px 이상은 날짜 / 회사·직무 / 업무·기술을 분리한다. 851–1200px은 날짜 / 본문 구성이다. 850px 이하는 기존 회사 선택을 유지한다.
- 연락처 전체의 어두운 배경, 이메일의 밝은 대형 배너, 큰 원형 화살표와 이메일만 펼치는 애니메이션을 제거했다. 이메일과 전화는 동일한 크기·배경·여백과 작은 선 아이콘을 사용한다. 근무 지역·관심 분야도 같은 두 행 구조다. 네 행의 등장 애니메이션은 동일하다.
- 회사·업무·기간·연락처의 실제 정보와 원본 증명사진은 유지했다.

## Validation

실제 배포 GSAP + JSDOM 검사에 소스의 viewport 미디어 조건을 선택하는 검증을 추가했다. 1920×1080, 1366×768, 1200×900, 1024×768, 851×900, 850×900, 768×1024, 390×844, 320×667에서 공통 본문 폭, 좌우 margin, 경력 표시 회사 수, 모바일 선택 UI, 이메일·전화의 같은 강조도를 확인했다. 기존 휠·터치·키보드 전환, 빠른 회사 선택, 게이지, 전체 보기 분리 행, 연락처 링크와 모션 완료 검사도 통과했다.

이 검증은 CSS 규칙 선택과 DOM 동작 검증이다. 실제 글줄 배치나 스크린샷 검증으로 간주하지 않는다. 관리형 로컬 미리보기 서비스가 없어 수정된 포트폴리오를 브라우저에서 렌더링하지 못했다. Wix 참고 화면은 실제 확인했으나 이것이 포트폴리오의 시각 검증을 대신하지 않는다.
