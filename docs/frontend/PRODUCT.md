# Product

## Platform

web

## Purpose

박주호의 공개 개인 포트폴리오. 제공된 이력, 웹 개발 경험, AI를 활용하는 개발 방식, 기초 네트워크 및 CCTV 기술지원 경험을 정확히 소개한다. 채용 담당자가 주요 독자라는 점은 이력서와 희망 직무로부터 도출한 작업 가정이다.

## Confirmed constraints

- 로그인 없이 공개. 기존 Sites 프로젝트와 URL을 유지한다.
- 한 번의 수직 휠 입력으로 한 섹션씩 이동하는 전체 화면 카드 구조.
- 항상 켜진 모션, 모션 토글 없음. 기본 읽기와 키보드 탐색 가능.
- 1920×1080에서 첫 소개가 한눈에 들어오고, 상세 보기 버튼이 내용을 덮지 않는다.
- 실제 증명사진을 사용하며, 최근 줄인 사진 크기를 불필요하게 키우지 않는다.
- 파란색 정체성을 유지하며 정갈하고 읽기 쉽게, 입체적인 상호작용을 구현한다.
- AI만 별도의 파란 영역으로 강조하지 않는다.
- 블렌딩에서 Webflow와 전자정부프레임워크 사용. PostgreSQL과 Supabase 사용 경험. 기초 네트워크와 CCTV 관심 분야 포함.
- 프로젝트는 계속 추가할 예정. 과장된 성과, 가짜 프로젝트나 숙련도 수치를 만들지 않는다.
- 2026-09-23 제공된 시안 7장 중 1·2·7번에 배경 이미지 3개를 적용한다. 3~6번은 시안의 머리말·여백·카드 정렬을 참고한다.
- 시안 전체를 스크린샷으로 붙이지 않고 실제 사진·문구·연락 링크와 기존 탐색 동작을 유지한다.

## Evidence

사용자가 제공한 이력서, assets/images/profile.png, 현재 포트폴리오 구현, 사용자가 공유한 Canva 자료 링크. 검증된 성과 수치나 개별 고객 프로젝트 이미지는 없다.

## Implementation

HTML/CSS/JavaScript, GSAP와 Three.js. 소스는 frontend/, 공유 정적 자산은 assets/에서 관리한다. CSS는 frontend/styles/의 역할별 파일로 구분하며, dist/는 빌드로 생성하는 정적 배포 디렉터리다. 공개 연락처는 사용자가 제공한 이메일과 휴대전화 번호다.
