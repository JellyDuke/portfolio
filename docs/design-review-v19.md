# v19 — mobile experience

## Working contract

모바일 경력 섹션을 개선한다. 사용자가 이어서 공유한 Instagram 릴스와 같은 작성자의 다른 영상도 검토하도록 요청했다. 공개 링크 열기와 두 검색 엔진을 통한 원문 검색을 시도했으나 링크는 DisabledError, 검색은 관련 결과 없음으로 끝났다. 계정 이름과 영상 내용을 확인하지 못했으므로 영상에서 얻은 원칙이나 분석을 만들어 내지 않는다. 영상 참고 작업은 미완료이며, 아래 변경은 현재 코드에서 확인한 문제에 근거한다.

## Findings and changes

- 모바일에 데스크톱 제목 크기와 긴 설명이 남아 경력 본문의 세로 공간을 줄였다. 경력 제목을 28–30px로 정리하고 작은 화면의 중복 설명을 접었다.
- 회사 선택은 줄바꿈 가능한 개별 버튼이었다. 이름 길이에 맞춘 한 줄의 선택 영역으로 변경하고 글자 14px, 조작 높이 46px을 유지했다.
- 601–850px에서는 한 회사를 선택하면서도 날짜와 본문이 두 열로 남았다. 모바일·태블릿 선택 화면을 한 열로 통일했다.
- 회사명, 직무, 직급이 별도 줄로 쌓였다. 회사명 아래 직무·직급을 같은 메타데이터 행에 배치했다. 날짜와 재직 여부/기간도 한 행에 배치했다.
- 업무 내용은 16px을 유지하고 중복 문구만 줄였다. Webflow, 전자정부프레임워크, 반응형 UI·UX, 웹 표준·접근성, 현장 지원 등 사실은 유지했다.
- 현재 선택된 회사를 다시 누르면 내용이 0 opacity부터 다시 등장했다. 동일 항목 재선택은 그대로 유지하고, 빠른 회사 변경은 이전 tween을 정리한다.

## Proof and limits

기존 실제 GSAP + JSDOM 동작 검증에 동일 회사 재선택, 빠른 회사 변경 후 한 항목만 선택, 최종 내용 표시를 확인하는 회귀 검증을 추가했다. CSS PostCSS 파싱, JS 구문, git diff 검사와 해당 동작 검증을 수행한다. 문서의 회사 3곳과 본문 업무 4/2/3개는 유지한다.

관리형 preview service 요청 디렉터리가 여전히 없어 실제 모바일 화면을 렌더링하지 못했다. JSDOM 치수는 fixture이며 시각 검증이나 실제 기기 검증으로 주장하지 않는다. 공개 배포 성공은 배포 확인으로만 사용한다.
